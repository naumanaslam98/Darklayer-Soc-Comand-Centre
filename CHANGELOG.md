# Changelog

## 1.2.0 — Live Monitoring

- Added real-time `/ws/events` WebSocket event streaming.
- Added Live Events terminal-style dashboard with filters, pause/resume, counters, and event detail.
- Added recent event history and live statistics APIs.
- Added persistent macOS machine collector authentication using an agent API key.
- Hardened macOS Unified Log NDJSON parsing.
- Added 24/7 macOS `launchd` server and collector operation.
- Added severe-alert SMTP notification support.
- Added safer localhost defaults for dashboard and syslog.
- Added GitHub-safe environment generation, CI, and repository hygiene.
